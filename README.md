## How to install a Claude Skill (2 minutes)

**Claude.ai (web or desktop app)**
1. Download this repo: green **Code** button → **Download ZIP**, then unzip it.
2. Zip **one skill folder** (for example `viral-hook-generator`) so the ZIP contains that folder.
3. In Claude, open **Customize → Skills**, click **+**, and upload the ZIP.
4. Start a new chat and ask normally. Claude switches the skill on when the task fits.

**Claude Code**
Copy a skill folder into `~/.claude/skills/` (or `.claude/skills/` in your project).

Works with Claude Free, Pro, Max and team plans.
