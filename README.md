## How to install a Claude Skill (2 minutes)

**Claude.ai (web or desktop app)**
1. Download this repo: green **Code** button → **Download ZIP**, then unzip it.
2. Zip **one skill folder** (for example `viral-hook-generator`) so the ZIP contains that folder.
3. In Claude, open **Customize → Skills**, click **+**, and upload the ZIP.
4. Start a new chat and ask normally. Claude switches the skill on when the task fits.

**Claude Code**
Copy a skill folder into `~/.claude/skills/` (or `.claude/skills/` in your project).

Works with Claude Free, Pro, Max and team plans.

## FAQ

### What are Claude Skills?

A Claude Skill is a folder with a SKILL.md file that teaches Claude how to do one job well. Once installed, Claude uses it automatically whenever your request fits, so you stop repeating the same instructions in every chat.

### How do I install a Claude Skill?

Zip one skill folder, then upload the ZIP in Claude under Customize → Skills. In Claude Code, copy the folder into ~/.claude/skills/. It takes about 2 minutes.

### Do Claude Skills work on the free plan?

Yes. Skills work on Claude Free, Pro, Max and team plans, on the web and desktop app, and in Claude Code.

### Can I edit these skills?

Yes. Open SKILL.md in any text editor and change the questions, defaults or output format to fit your work. They are MIT licensed.
